# Crud-Futebol.
Este projeto foi desenvolvido para fins de estudo e prática com Java e JDBC (Java Database Connectivity) para manipulação de dados em um banco de dados MySQL. O objetivo é implementar operações básicas de CRUD (Criar, Ler, Atualizar e Deletar) sem o uso de frameworks, focando no uso direto do JDBC para interação com o banco de dados.
